# Reusable Component Examples

## Tech Stack

- React
- React Router
- JavaScript
- Tailwind CSS
- Vite

## Reusable Components

### SectionHeader

Reusable section component supporting:

- Heading
- Paragraph
- Centered layout
- Optional CTA
- CTA color variations
- Custom classes

### LinkGhost

Reusable navigation link built with React Router's `NavLink`.

Supports:

- Multiple color variations
- Custom Tailwind classes
- Responsive styling
- Hover transitions

## Getting Started

```
npm install
npm run dev
```
